ЧТО СДЕЛАНО В КОДЕ:

✅ Промпт запрещает ** __ * _ и другие Markdown символы
✅ Функция clean_latex() удаляет ** если модель их добавила
✅ Математика: краткий стиль "Дано → Решение → Ответ"
✅ Русский язык: читабельное форматирование с разделением строк
✅ Химия: примеры без ** для коэффициентов
✅ Команды: убраны /stats и /help, /model через кнопки
✅ /clear безопасная - удаляет только историю

═══════════════════════════════════════════════════════════

ЧТОБЫ ВСЁ ЗАРАБОТАЛО:

1. Останови бота (Ctrl+C в консоли где он запущен)

2. Удали базу данных:
   del bot_data.db

3. Запусти бота заново:
   python bot_with_logs.py

4. Протестируй:
   • Математика - должна быть структура Дано/Найти/Решение/Ответ
   • Химия - коэффициенты БЕЗ звездочек: 2H₂O (не **2**H₂O)
   • Русский - каждое предложение с новой строки
   • /model - должны быть кнопки для выбора

═══════════════════════════════════════════════════════════

ПОЧЕМУ НУЖНО УДАЛИТЬ БАЗУ:

База данных bot_data.db хранит старый промпт для каждого 
пользователя. Даже если код обновлен, бот использует промпт 
из базы. После удаления базы бот создаст новую с актуальным 
промптом.

═══════════════════════════════════════════════════════════

АЛЬТЕРНАТИВА (без остановки бота):

Отправь боту команду:
   /reset

Это сбросит твои настройки и применит новый промпт.
Но лучше удалить базу полностью для всех пользователей.

═══════════════════════════════════════════════════════════

КОМАНДЫ БОТА:

/start - Запуск бота
/model - Выбор модели (кнопки: Gemini/Groq/Авто)
/clear - Очистить историю диалога
/reset - Полный сброс (история + настройки)

═══════════════════════════════════════════════════════════

ПРОВЕРКА ЧТО ВСЁ РАБОТАЕТ:

1. Математика:
   Отправь задачу по геометрии
   Должно быть: Дано → Найти → Решение (кратко) → Ответ

2. Химия:
   Отправь уравнения для расстановки коэффициентов
   Должно быть: 2H₂ + O₂ → 2H₂O (БЕЗ **)

3. Русский:
   Отправь предложения для грамматических основ
   Должно быть: каждое предложение с новой строки

4. Команды:
   /model - должны появиться кнопки
   /stats и /help - не должны работать
