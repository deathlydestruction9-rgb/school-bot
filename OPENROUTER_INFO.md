# 🔄 OpenRouter - Что это и что дает

## 🤔 Что такое OpenRouter?

OpenRouter - это **агрегатор AI моделей**. Один API ключ дает доступ к 290+ моделям от разных провайдеров:
- Google (Gemini)
- OpenAI (GPT)
- Anthropic (Claude)
- Meta (Llama)
- DeepSeek
- Mistral
- И многие другие

**Главное преимущество:** Один API ключ вместо десятков разных.

### 📊 Лимиты бесплатных моделей:

**Основные ограничения:**
- Дневные лимиты запросов (зависит от модели)
- Ограничение скорости (медленнее платных)
- Качество такое же, как у платных версий

**Проблема для школьного бота:**
- Бесплатные модели с поддержкой фото **очень ограничены**
- Gemini на OpenRouter теперь **платный**
- Лучше использовать прямой API Google

## 🎯 Стоит ли использовать OpenRouter для школьного бота?

### ❌ НЕ рекомендуется, если:

1. **Нужна поддержка фото** - Gemini бесплатно только через прямой API Google
2. **Нужна стабильность** - бесплатные модели часто меняются
3. **Простота важнее** - проще использовать прямые API

### ✅ Рекомендуется, если:

1. **Хочешь экспериментировать** с разными моделями
2. **Нужен запасной вариант** когда основные API не работают
3. **Готов платить** - тогда OpenRouter очень удобен (один счет для всех моделей)

## 🔧 Если все же хочешь попробовать OpenRouter

### Регистрация:
1. Открой https://openrouter.ai
2. Зарегистрируйся
3. Получи API ключ

### Использование бесплатных моделей:

```python
import httpx

async def call_openrouter_free(messages, system_prompt):
    url = "https://openrouter.ai/api/v1/chat/completions"
    
    # Бесплатные модели (без изображений):
    free_models = [
        "meta-llama/llama-3.3-70b-instruct:free",
        "nvidia/nemotron-3-super:free",
        "mistralai/mistral-small:free"
    ]
    
    formatted_messages = [{"role": "system", "content": system_prompt}]
    for msg in messages:
        formatted_messages.append({"role": msg["role"], "content": msg["content"]})
    
    async with httpx.AsyncClient(timeout=30.0) as client:
        response = await client.post(
            url,
            headers={
                "Authorization": f"Bearer {OPENROUTER_API_KEY}",
                "Content-Type": "application/json"
            },
            json={
                "model": free_models[0],  # Выбери модель
                "messages": formatted_messages
            }
        )
        
        if response.status_code == 200:
            data = response.json()
            return data['choices'][0]['message']['content']
        else:
            raise Exception(f"OpenRouter error: {response.status_code}")
```

### ⚠️ Проблемы с бесплатными моделями:

1. **Нет Gemini бесплатно** - только платно
2. **Лимиты меняются** - модели добавляются/удаляются
3. **Медленнее** - бесплатные модели в очереди
4. **Нет гарантий** - могут убрать в любой момент

## 🎓 Вывод для школьного бота

### Рекомендация: НЕ используй OpenRouter для бесплатного бота

**Причины:**
1. Gemini (лучший для фото) - платный на OpenRouter
2. Прямые API дают больше бесплатных запросов
3. Проще в настройке и поддержке

### Используй вместо этого:

```
Gemini API (прямой)     → 1,500 запросов/день с фото
    +
Groq Vision API         → 14,400 запросов/день с фото
    +
Groq Text API           → 14,400 запросов/день текст
    =
30,300 запросов/день БЕСПЛАТНО!
```

### OpenRouter полезен только если:

1. **Готов платить** - тогда удобно иметь один счет
2. **Нужны экзотические модели** - которых нет в прямых API
3. **Хочешь экспериментировать** - с разными моделями
