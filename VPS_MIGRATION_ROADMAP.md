## Полезные команды 🛠️

### Управление PM2
```bash
pm2 status                    # Статус всех процессов
pm2 logs school-bot          # Логи бота
pm2 restart school-bot       # Перезапуск
pm2 stop school-bot          # Остановка
pm2 delete school-bot        # Удаление
pm2 save                     # Сохранить конфигурацию
```

### Обновление кода
```bash
cd /root/telegram-bot
git pull origin main         # Обновить из GitHub
pm2 restart school-bot       # Перезапустить бота
```

### Проверка логов
```bash
pm2 logs school-bot --lines 100    # Последние 100 строк
pm2 logs school-bot --err          # Только ошибки
tail -f /root/.pm2/logs/school-bot-out.log  # Следить за логами
```
