  ИНСТРУКЦИЯ: КАК ПРИМЕНИТЬ НОВЫЙ ПРОМПТ БЕЗ ** ЗВЕЗДОЧЕК
═══════════════════════════════════════════════════════════

ПРОБЛЕМА:
Бот выдает коэффициенты с ** звездочками: **2**H₂O вместо 2H₂O

ПРИЧИНА:
Старый промпт сохранен в базе данных bot_data.db

═══════════════════════════════════════════════════════════

РЕШЕНИЕ (выбери один способ):

┌─────────────────────────────────────────────────────────┐
│ СПОСОБ 1: Автоматический (РЕКОМЕНДУЕТСЯ)               │
└─────────────────────────────────────────────────────────┘

1. Останови бота (Ctrl+C в консоли где он запущен)

2. Запусти файл:
   restart_bot.bat

   Он автоматически:
   • Удалит старую базу данных
   • Запустит бота с новым промптом

┌─────────────────────────────────────────────────────────┐
│ СПОСОБ 2: Ручной                                        │
└─────────────────────────────────────────────────────────┘

1. Останови бота (Ctrl+C)

2. Удали файл базы данных:
   del bot_data.db

3. Запусти бота заново:
   python bot_with_logs.py

┌─────────────────────────────────────────────────────────┐
│ СПОСОБ 3: Через команду бота (без остановки)           │
└─────────────────────────────────────────────────────────┘

Отправь боту команду:
   /reset

Это сбросит настройки и применит новый промпт.

═══════════════════════════════════════════════════════════

ПРОВЕРКА:

После перезапуска отправь боту фото с химическими 
уравнениями. Он должен ответить БЕЗ ** звездочек:

✅ ПРАВИЛЬНО:
   2H₂ + O₂ → 2H₂O
   2Mg + O₂ → 2MgO

❌ НЕПРАВИЛЬНО (старый промпт):
   **2**H₂ + O₂ → **2**H₂O
   **2**Mg + O₂ → **2**MgO
